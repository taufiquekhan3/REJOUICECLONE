# Rejouice Clone

A visually engaging React website inspired by Rejouice, built to provide an immersive user experience using **Framer Motion** and **GSAP** for animations.

## Features
- **Smooth Animations:** Leveraging **Framer Motion** and **GSAP** for interactive, dynamic UI effects.  
- **User-Centric Design:** Focused on providing a seamless and visually appealing browsing experience.  
- **Responsive Layout:** Fully responsive across devices — mobile, tablet, and desktop.  
- **Modern React Architecture:** Built with **React** and **Vite** for fast development and performance.  

## Technologies Used
- **React** – Frontend library for building UI components  
- **Vite** – Build tool for faster development and optimized production build  
- **Framer Motion** – Animation library for smooth, declarative transitions  
- **GSAP (GreenSock)** – Advanced animation library for complex motion effects  
- **CSS / SCSS** – Styling and layout
